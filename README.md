# 🕹️ Othello  
السلام عليكم ورحمة الله  

I present to you my first React project — a game called **Othello** 🎮.  
You can play **PvE** (against the AI) or **PvP** (against another player), and you can also choose the bot’s difficulty level.  

---

## 🧠 Note  
There are some memory issues, so it’s better **not to try very high difficulty levels** for the bot.  
You can still experiment to understand how it works.  

---
